02 / WHY

手机不该只是
消费内容的地方。

灵感不挑场合。可笔记本不在手边时，大多数移动编辑器只够「看一眼代码」。 SLIPE 想把「改、跑、发」这三件事，完整地留在手机上。

01

够用的编辑器，不是预览器

多标签、文件树、语法高亮、查找替换与多光标。外接键盘时，它就是一台缩小的工作站。

02

AI 改代码，过程可回滚

每一次工具调用、每一处 diff 都摊开给你看。不满意，一键撤回，不需要重来。

03

构建在云端，产物回手机

GitHub Actions 与 Gitee Go 接力编译，手机只负责发起与收件——不烫手，也不占存储。

08 / FAQ

你可能
想问。

还有问题？到社区发帖，或加入官方 QQ 群。

需要 Root 或特殊权限吗？

不需要。SLIPE 以普通应用方式运行；Termux 终端为可选项，仅在检测到已安装 Termux 时启用入口。

云端构建怎么收费？

构建本身走你自己的 GitHub Actions / Gitee Go 额度，SLIPE 只负责任务编排、状态同步与产物回传，不额外收取构建费。AI 对话按积分计费。

支持哪些语言和框架？

编辑器对主流语言提供语法高亮与基础补全；云端构建目前针对 Flutter / Android 链路做了完整适配，其它技术栈可按仓库自定义工作流。

项目和数据会上传吗？

项目文件保存在本机。只有你主动开启的云端同步（项目列表、偏好、会话）会写入 SLIPE 账号；AI 对话仅发送当前请求所需上下文。隐私政策随版本公开。

换手机后数据还在吗？

登录同一账号即可恢复项目列表、偏好设置、AI 会话与积分。若在旧设备开启过云端壁纸与头像，也会一并同步。

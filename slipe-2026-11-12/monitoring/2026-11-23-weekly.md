## 2. 净新增信号（仅列窗口内首次公开的事实）

### 2.1 DeepSeek 开放应用级 API 全量能力（2026-11-13）｜影响：成本 + 生态

**事实**
- DeepSeek API 变更日志 2026-11-13 发布 "Releasing the full suite of application APIs"。
- `deepseek-flash` 在 Messages / Responses / Chat Completions 三类接口中支持：联网搜索（关闭思考）、深度思考搜索（开启思考）、文件输入（PDF/Office/图片，含版面解析）、URL 读取、模型安全（输入输出风险审查，命中返回拒答标记）。
- 同时把 Search & Fetch、OCR、ASR、TTS 作为独立 API 开放，并提供可导入历史会话的开源 Demo 客户端。
- 来源：<https://api-docs.deepseek.com/updates/>

**推断**
- 对 SLIPE 的"轻量编辑 + 受控免费云任务"是**利好**：搜索、文件解析、语音不必自建 RAG/解析链路，可显著缩短"云任务"功能上线周期。
- 但"全量能力"意味着单次任务的 token 与工具调用面变大，免费档成本更易失控；需要按任务类型拆分额度。
- 安全参数可作为合规辅助，但**不等于**完成备案或内容安全义务，仍需自行履行。

**90 天门槛**：**要调**。把"60 天建池 + BYOK"中的模型接入清单增加"应用级 API（搜索/文件/URL）"评估；免费任务门槛从"按请求数"改为"按 token + 工具调用"双阈值。

### 2.2 DeepSeek 服务端搜索/抓取不再单独计费（2026-11-18 12:00 北京时间生效）｜影响：成本

**事实**
- 官方定价页明确：自 2026-11-18 12:00（UTC+8）起，调用模型时触发的**服务端搜索与网页抓取工具调用不再单独计费**；其结果拼入模型上下文，按模型 token 计费。
- 触发入口包括 web tools、Anthropic API 的 `web_search`、Responses API 的 `web_search`。
- 仍单独计费的项目：Search API / Fetch API 直调（$0.75 / 千次成功请求）、文件解析与 OCR（$0.225 / 千页）、TTS/ASR（限时五折）。
- 来源：<https://api-docs.deepseek.com/quick_start/pricing>

**事实（当前目录价，未在本周变动）**

| 项目（每 1M tokens） | deepseek-flash 谷/峰 | deepseek-v4-pro 谷/峰 |
|---|---|---|
| 输入·缓存命中 | $0.003 / $0.006 | $0.022 / $0.044 |
| 输入·缓存未命中 | $0.15 / $0.30 | $0.66 / $1.32 |
| 输出 | $0.60 / $1.20 | $1.98 / $3.96 |

- 峰时为北京时间周一至周五 09:00–12:00、14:00–18:00（对应 UTC 01:00–04:00、06:00–10:00），法定节假日与周末全时段为谷时。
- 缓存命中价约为未命中的 2%；FIM 补全（Beta）**仅非思考模式**支持。

**推断**
- 计费从"按次工具费"转为"按 token"，对**高频小搜索**更便宜，对**长网页/多轮搜索**可能更贵；需按真实任务分布重算，而不是简单判定降价。
- 峰谷价差 2 倍，SLIPE 的"免费云任务"可把非实时任务调度到谷时，形成结构性成本优势（需产品侧可见地告知排队）。

**90 天门槛**：**要调**。在会员体系上线前，补一张"任务类型 × 峰谷 × 缓存"的单任务成本表；免费档日额度以 P95 成本而非均值设阈。

### 2.3 VS Code 退役 Local harness，统一到 Microsoft Copilot harness（2026-11-16 公告）｜影响：生态

**事实**
- VS Code 1.146 弃用 Local harness（负责 Copilot agent 会话的模型/上下文/工具编排），将于 **2027 年 2 月移除**。
- 替代品 Microsoft Copilot harness 自 VS Code 1.143 起为新会话默认；基于 Copilot SDK，与 Copilot CLI、Copilot app 共享运行时。
- 企业侧可用 `vscode.temporaryDefaultToLocalHarness` 临时例外，但该设置随 Local harness 一并移除。
- Copilot harness 支持管理员强制运行时权限与沙箱限制；并引入 Copilot connectors（预览）、canvases（预览）。
- 来源：<https://github.blog/changelog/2026-11-16-vs-code-retires-the-local-harness-in-february-2027/>
- 相关：微软 2026-10-28 发布 Copilot harness 博客 <https://blogs.microsoft.com/blog/2026/10/28/introducing-the-microsoft-copilot-harness-unlocking-the-potential-of-truly-multi-model-agentic-work/>；VS Code 博客 2026-11-18 "The Copilot harness: Building on a shared foundation"。

**推断**
- 这是**桌面端 agent 运行时收口**，不是扩展 API 破坏性变更；对 SLIPE 的直接 API 影响有限。
- 但"企业可强制 sandbox/权限"会成为采购方的默认预期，反向抬高了 SLIPE "受控免费云任务"的**可解释性门槛**（谁能跑、跑在哪、花多少）。
- 若 SLIPE 依赖 VS Code 兼容层承载社区插件，应避免把"兼容"叙事绑定到 Copilot harness 的私有能力上。

**90 天门槛**：**要调（轻）**。在"90 天转飞轮/社区市场"前，明确"受控云任务"的权限模型与审计口径；连接器只承诺**锁定版本的可验证兼容**，不做全量兼容承诺。

### 2.4 中国生成式 AI 备案：9–10 月新增 133 款，含 3 款手机端侧（2026-11-20）｜影响：合规

**事实**
- 国家网信办 2026-11-20 公告：2026 年 9–10 月新增 **133 款**生成式 AI 服务完成备案，其中含 **3 款提供手机端侧生成式 AI 服务**、1 款拟人化互动服务；1 款备案信息变更。
- 公告重申：通过 API 或其他方式直接调用已备案模型能力的应用/功能，需按规定履行**登记**等义务。
- 来源：<https://www.cac.gov.cn/2026-11/20/c_1796918603542950.htm>

**事实（基线前既发，仅作背景）**
- 2026-11-09：备案系统上线使用指南、常见问题答疑更新；"可灵大模型"备案单位信息变更；"新宇多模态大模型"拟人化互动场景备案公告。
- 《人工智能拟人化互动服务管理暂行办法》2026-04-10 公布、**2026-07-15 施行**（基线前既发）。
- 来源：<https://beian.cac.gov.cn/>

**推断**
- "手机端侧生成式 AI 服务"已有独立备案口径且出现获批案例，SLIPE 若在端侧跑轻量模型/离线补全，**很可能**需要单独判定备案或登记路径；若仅调用已备案云端模型，则走"登记"路径。
- 该判定会直接影响国内版上线节奏，属于 go/no-go 级合规事项。

**90 天门槛**：**要调**。在"30 天收钱"前增加一项硬门槛：完成"端侧 vs 云端调用"的备案/登记适用性书面判定；未判定不得开放国内付费。

### 2.5 加州 CCPA：数据经纪与 DROP 审计规则征求意见开启（2026-11-13）｜影响：合规（低）

**事实**
- CalPrivacy 公告：数据经纪更新与 DROP 审计规则正式征求意见期 **2026-11-13 至 2027-01-06**。
- 另：2026-11-06 董事会 5–0 通过，指示就 opt-out preference signals（OOPS）等启动正式规则制定。
- 来源：<https://cppa.ca.gov/regulations/> 、<https://www.wsgr.com/en/insights/calprivacy-signals-a-harder-line-on-gpc-cookie-banners-and-data-broker-deletions-takeaways-from-november-board-meeting.html>

**推断**
- SLIPE 不是数据经纪商，DROP 规则无直接影响。
- 但 OOPS/退出信号执法趋严，SLIPE 官网与 Web 版的 cookie/退出入口需按"可测试、可审计"标准实现，避免营销站成为合规短板。

### 3.9 欧盟 GDPR / AI Act — 本周无实质变化
- AI Act：Digital Omnibus（Regulation (EU) 2026/1744）2026-07-24 公布、2026-07-27 生效；Annex III 高风险期限延至 **2027-12-02**，Annex I 延至 **2028-08-02**；生成式透明度义务自 2026-08 起适用。均早于基线。
- GDPR：EDPB 2026-11-10 会议选定 2027 协调执法主题（招聘场景 AI 自动化决策），属执法规划，非新规。

**判断**：本周无实质变化。SLIPE 若面向欧盟，优先级仍是"AI 生成内容标识 + 隐私政策 + 数据留存"三件事。

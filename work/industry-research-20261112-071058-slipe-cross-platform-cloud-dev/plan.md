# 研究计划

## 用户目标
为 SLIPE Flutter 跨端代码编辑器形成可执行的 SWOT 竞品分析、市场推广方案与未来市场规划，验证“轻量化 + 跨端同步 + 桌面端扩张 + 免费云开发排队 + 获客与自主云算力摊薄成本 + DeepSeek Harness 兼容与自建编辑器插件生态”的方向、约束与实施顺序。

## 范围
- 行业定义：以跨端代码编辑、跨设备项目同步、云端开发或构建、AI 编程辅助及编辑器插件生态为核心的开发者工具；SLIPE 为研究主体，Flutter 跨端一致性是其差异化边界。
- 包含：全球与中国可获取的桌面 AI IDE、云开发环境、移动/跨端开发工具、相关云构建与插件生态；开发者需求、商业模式、成本与合规；SWOT、获客、产品与市场路线图。
- 不包含：低代码/无代码平台的市场份额、通用云计算整体市场、证券投资估值或选股、未经证实的 SLIPE 用户与收入数据；不把相邻市场直接计入 SLIPE 可服务市场。
- 地域：产品与竞品以全球为主；获客、支付、数据与生成式 AI 合规重点看中国。
- 资料截止日：2026-11-12
- 历史观察期：以资料截止日可确认的最新完整年度及最新部分年度为准；竞品近期信号以首次基线的近30日为重点，融资、组织和政策可延伸至近90日。
- 预测期：无；仅提供带假设与触发条件的三阶段行动规划，不发布确定性市场预测。
- 指定企业或焦点：用户指定关注 VS Code 插件迁移与 DeepSeek Harness 插件生态；重点企业样本由正式研究根据竞争结构和证据确定。

## 研究问题
### 宏观与政策环境分析
- 核心问题：中国及主要海外市场针对云端代码、生成式 AI、个人信息与跨境数据的哪些规则会影响免费云开发、账号同步和 AI 代理？
- 重要问题：开源许可、VS Code 插件分发条款及应用商店规则对兼容与官方移植有什么边界？

### 市场规模测算
- 核心问题：是否有可靠公开数据支持开发者工具、AI 编码或云开发环境的市场规模与增速，能否作为 SLIPE 的方向性参照？
- 重要问题：缺少直接口径时，如何用开发者数量、可服务客群与自下而上的单位经济模型建立不夸大的 SAM/SOM 假设？主要指标为相关市场规模，辅助指标为全球开发者/专业开发者数量。

### 产业链分析
- 核心问题：从模型、编辑器内核、插件与源码托管，到云算力、构建、分发和支付的链条中，SLIPE 的价值与依赖是什么？
- 重要问题：免费队列、资源共享、自主算力和构建缓存可如何影响成本、体验与供应风险？

### 竞争格局分析
- 核心问题：桌面 AI IDE、通用云 IDE、移动编码与 Flutter 相关工具各自如何竞争，SLIPE 应避免哪些正面战场？
- 重要问题：跨端一致性、轻量、同步、免费云队列、DeepSeek Harness 兼容和 VS Code 插件迁移是否构成可防御差异；主要竞品的价格、平台、生态与近期动作是什么？

### 重点企业研究
- 核心问题：哪些代表企业能解释主流桌面 IDE、AI 原生 IDE、云开发及移动开发路线，它们的产品和商业化有何差异？
- 重要问题：用户指定的 Microsoft/VS Code 与 DeepSeek 生态之外，选择哪些三至五个代表主体进行同维度比较；其公开动作对 SLIPE 有何可验证启示？

### 趋势、机会与风险研判
- 核心问题：已核实事实支持哪些产品、生态、获客与成本路线，哪些只是待验证假设？
- 重要问题：SLIPE 应设置哪些阶段门槛、止损条件和监测信号，以避免免费算力失控、桌面体验不足和插件维护负担？

## 运行的研究步骤
1. 宏观与政策环境分析
2. 市场规模测算
3. 产业链分析
4. 竞争格局分析
5. 重点企业研究
6. 趋势、机会与风险研判
7. 研究报告撰写与关键事实核查
8. 在独立策略交付物中完成 SWOT、市场推广、预算/KPI 和未来市场规划

## 报告结构
行业概览、市场规模、产业链与关键瓶颈、竞争格局、重点企业、宏观与政策环境、趋势机会与风险，以及核心结论、结论与展望和可点击参考资料。另行形成面向项目决策的 SWOT、竞品矩阵、GTM、三阶段路线图、单位经济与监测机制。

## 假设
- 项目现有代码与文档只用于确认产品事实，不把规划文档当作已上线能力。
- 未取得 SLIPE 真实用户、留存、收入和云成本数据前，所有经营目标与预算均明确标为建议目标或情景假设，不伪装成历史业绩。
- 免费云开发的可持续性必须用排队、配额、单位任务成本和付费/获客回收共同验证，不能仅以获客规模推断成立。
- 插件“兼容”按实际许可、API 与运行时适配程度分级，不宣称可直接运行全部 VS Code 插件。
